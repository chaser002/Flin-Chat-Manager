# Flin Chat Manager

Telegram-бот для централизованного управления участниками нескольких групп. Администратор исключает или блокирует человека в одном чате или сразу во всех подключённых, а единый Blacklist не пускает нарушителей в другие чаты.

Бот работает только в группах и супергруппах. В личные сообщения он не пишет и на них не отвечает. Все ответы приходят в тот чат, где вызвана команда.

## Возможности

- Локальные команды: `/kick`, `/ban`, `/unban`
- Глобальные команды с подтверждением кнопкой: `/globalkick`, `/globalban`, `/globalunban`
- Единый чёрный список: `/addblacklist`, `/removeblacklist`, `/blacklist`, `/checkblacklist`. Пользователь из списка, вступивший в любой подключённый чат, блокируется автоматически или об этом уведомляется администрация
- Информация о пользователе: `/userinfo`
- Подключённые чаты регистрируются автоматически: `/chats`
- Журнал всех административных действий: `/logs`
- Цель команды задаётся ответом (Reply) на сообщение или Telegram ID: `/ban 123456789 спам`

## Как устроена безопасность

- **Авторизованные администраторы.** Командами управления пользуются только Telegram ID из `ADMIN_IDS`. Остальным бот отвечает «Недостаточно прав» (не чаще раза в минуту). Права проверяются перед каждой командой и перед каждым подтверждением.
- **Подтверждение.** Глобальные операции выполняются только после нажатия «Подтвердить» тем же администратором. Запрос одноразовый и действует ограниченное время (`CONFIRM_TTL_SECONDS`).
- **Защита от повторов.** Два одинаковых запроса одновременно не выполняются параллельно, повторное сообщение не обрабатывается дважды, глобальные операции идут по одной.
- **Защищённые цели.** Нельзя применить команды к самому боту, к себе, к авторизованным администраторам, к анонимным администраторам и каналам. Команды от имени ботов игнорируются.
- **Служебные чаты.** Подробные административные данные (причины блокировок, журнал, Blacklist, список чатов, история наказаний, подробный отчёт по чатам) бот показывает только в чатах из `ADMIN_CHAT_IDS`: это закрытые группы только для администраторов. В обычных чатах бот выводит ограниченный формат: счётчики и итог операции без названий других чатов и без причин.
- **Журнал.** Для каждого действия сохраняются тип, исполнитель, цель, чат, причина, дата и результат. Глобальные операции записываются отдельно по каждому чату.
- **Честные результаты.** Действие считается выполненным только после подтверждения Telegram API. Бот не может получить список участников группы, поэтому в глобальных операциях он проверяет статус человека в каждом подключённом чате отдельным запросом.

## Команды

| Команда | Что делает |
|---|---|
| `/kick` | исключить из текущего чата (вернуться можно) |
| `/ban` | заблокировать в текущем чате |
| `/unban` | снять блокировку в текущем чате |
| `/globalkick` | исключить из всех подключённых чатов |
| `/globalban` | заблокировать во всех подключённых чатах |
| `/globalunban` | снять блокировку во всех подключённых чатах |
| `/addblacklist` | добавить в Blacklist (ID, имя, причина, дата и администратор сохраняются) |
| `/removeblacklist` | удалить из Blacklist |
| `/blacklist` | показать список Blacklist (подробно только в служебном чате) |
| `/checkblacklist` | проверить пользователя (результат только в служебном чате) |
| `/userinfo` | имя и ID. Без аргументов показывает данные автора команды |
| `/chats` | подключённые чаты и их статус (подробно только в служебном чате) |
| `/logs [число]` | последние действия, от 1 до 20 (только в служебном чате) |

Команды управления, `/blacklist`, `/checkblacklist`, `/chats` и `/logs` доступны только авторизованным администраторам. `/userinfo` доступна всем, но административные сведения (Blacklist, число чатов, история и причины наказаний) она показывает только администраторам и только в служебных чатах.

Примеры ответов:

```
Пользователь успешно исключён из текущего чата.
ID пользователя: 123456789
Администратор: Vladislav
Причина: Нарушение правил.
```

```
Глобальное исключение завершено.

Успешно: 8 чатов.
Не удалось: 2 чата.
Всего проверено: 10 чатов.

Подробности доступны в отчёте.
```

```
Пользователь добавлен в Blacklist.

ID: 123456789
Причина: Нарушение правил.
Добавил: Vladislav.
```

## Структура проекта

```
main.py                  запуск бота
config.py                конфигурация из .env и переменных окружения
database.py              база данных SQLite (создаётся при первом запуске)
handlers/
  moderation.py          kick, ban, unban и глобальные команды
  blacklist.py           Blacklist и реакция на вступление
  userinfo.py            /userinfo
  chats.py               регистрация чатов и /chats
  logs.py                /logs
middlewares/
  chat_filter.py         только группы, без ботов, без повторов
  access.py              проверка администратора
  tracker.py             запоминание имён пользователей
services/
  moderation.py          действия в одном и во всех чатах
  confirmations.py       подтверждения и блокировки от повторов
  blacklist.py           реакция на пользователя из Blacklist
  chats.py               актуализация прав бота
  users.py               определение имени
utils/
  helpers.py, errors.py, targets.py, texts.py
requirements.txt  .env.example  .gitignore
```

## Шаг 1. Создайте бота в BotFather

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Введите название (например, Flin Chat Manager) и username, который заканчивается на `bot`.
3. Скопируйте токен вида `123456789:AA...`. Никому его не показывайте и не добавляйте в репозиторий.
4. Остальные настройки можно не менять. Группы бот-администратор видит и без отключения Group Privacy.

## Шаг 2. Настройте .env

Скопируйте `.env.example` в `.env` и заполните:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от BotFather (обязательно) |
| `ADMIN_IDS` | Telegram ID администраторов через запятую (обязательно). Свой ID покажет бот **@userinfobot** |
| `ADMIN_CHAT_IDS` | ID служебных чатов (необязательно, но без него подробные данные нигде не показываются) |
| `BLACKLIST_ACTION` | `ban` или `notify`: что делать с вступившим пользователем из Blacklist |
| `CONFIRM_TTL_SECONDS` | время действия подтверждения, по умолчанию 90 |
| `TZ_OFFSET_HOURS` | часовой пояс для дат, по умолчанию 2 |
| `LEAVE_UNAUTHORIZED_CHATS` | `1`: бот выходит из чатов, куда его добавил не администратор из `ADMIN_IDS` |
| `DB_PATH` | путь к базе данных, по умолчанию `data/flin_chat_manager.db` |
| `LOG_LEVEL` | уровень журнала бота |

ID служебного чата узнать просто: добавьте бота в закрытую группу администраторов и отправьте там `/chats`. Бот ответит и покажет ID этого чата. Впишите его в `ADMIN_CHAT_IDS` и перезапустите бота.

## Шаг 3. Добавьте бота в группы

1. Добавьте бота в каждую группу, которой нужно управлять.
2. Сделайте бота администратором группы с правом **«Блокировка пользователей»** (Ban users). Без него бот не сможет ни исключать, ни блокировать. Остальные права не нужны.
3. Бот зарегистрирует группу сам. Статус и наличие прав видны в `/chats` (в служебном чате).
4. Бот должен быть администратором ещё и ради автоматической реакции на вступление: Telegram присылает такие события только администраторам.
5. Ограничение Telegram: бот не может исключить или заблокировать администратора или владельца чата. Такие чаты в отчёте попадут в «Не удалось».

## Шаг 4. Запуск на своём компьютере

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # затем заполните .env
python main.py
```

База данных и папка `data/` создаются при первом запуске.

## Запуск через GitHub и хостинг (например, Bot-Hosting)

1. Создайте на GitHub **публичный** репозиторий. Токен и `.env` в него добавлять нельзя.
2. Загрузите все файлы и папки проекта через **Add file → Upload files**, перетащив их в окно браузера. Папки `handlers`, `middlewares`, `services` и `utils` должны сохраниться, а файлы `__init__.py` внутри них тоже загружаются. Файл `.env` не загружайте.
3. На хостинге создайте проект Python и подключите репозиторий.
4. Во вкладке **Environment** добавьте переменные из таблицы выше: как минимум `BOT_TOKEN` и `ADMIN_IDS`. Хостинг передаёт их боту как переменные окружения, и `.env` не нужен.
5. Файл запуска: `main.py`. Зависимости ставятся из `requirements.txt`.
6. Нажмите Restart и проверьте в консоли строку «Flin Chat Manager запущен как @...».

Данные бота лежат в файле базы (`data/flin_chat_manager.db`). Периодически сохраняйте его копию: при пересоздании проекта на хостинге он может пропасть.

## Проверка после запуска

1. В любой группе, где бот администратор, администратор из `ADMIN_IDS` отправляет `/chats`: бот должен ответить.
2. Тестовый аккаунт, не из `ADMIN_IDS`, отправляет `/kick`: бот отвечает «Недостаточно прав».
3. Администратор отвечает на сообщение тестового аккаунта командой `/kick тест`: тестовый аккаунт исключён, в чат пришёл ответ в нужном формате.
4. `/globalkick` по ID тестового аккаунта: бот просит подтверждение, после нажатия «Подтвердить» присылает итоговый отчёт.
5. В служебном чате `/logs` показывает выполненные действия.

## Ограничения Telegram, которые учтены

- Бот не получает список участников группы, поэтому глобальные операции проверяют статус пользователя в каждом подключённом чате запросом к API.
- Бот не может действовать в чатах, где он не состоит или не имеет права блокировки. Такие чаты указываются в отчёте.
- Блокировка заранее (пользователь не состоит в чате) работает в супергруппах. В обычных группах снятие блокировки недоступно: исключённый там может вернуться сам.
- При превышении лимитов запросов бот ждёт и повторяет попытку, между чатами делается небольшая пауза.
- Автоматическая реакция на пользователей из Blacklist срабатывает при вступлении в чат. Тех, кто уже состоит в чатах, исключает `/globalkick` или `/globalban`.

## Данные и приватность

Бот хранит только Telegram ID, имя и username людей, которых видит в подключённых чатах (для показа имени по ID), записи Blacklist, список чатов и журнал действий. Содержимое сообщений он не сохраняет.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Бот не отвечает на команды | Проверьте ваш ID в `ADMIN_IDS`, что бот администратор чата и что команда отправлена в группе, а не в личке |
| «Ошибка конфигурации» при запуске | Не заданы `BOT_TOKEN` или `ADMIN_IDS` |
| В отчёте «у бота нет прав» | Выдайте боту в этом чате право блокировки пользователей |
| В отчёте «администратор или владелец чата» | Telegram не позволяет боту применять наказания к администраторам |
| `/blacklist`, `/logs` пишут про служебные чаты | Добавьте ID закрытой группы администраторов в `ADMIN_CHAT_IDS` |
| Пользователь из Blacklist вошёл, но не заблокирован | Бот не администратор в этом чате или нет права блокировки |
